# nstHelper

A full stack web app built to help students practice questions and MCQs for NST exams. It has a React frontend where users can browse exams, attempt questions, and check answers. The backend runs on Express with MongoDB for storing users, exams, questions, and MCQs. There is also a separate admin panel for managing content.

The frontend is built with React and Tailwind CSS using Vite. Backend uses Express, Mongoose, JWT for auth, and Nodemailer for sending emails. The admin page is a standalone React app.

## Tech Stack

- Frontend - React, Tailwind CSS, Redux Toolkit, React Router
- Backend - Node.js, Express, MongoDB, Mongoose
- Admin Panel - React
- Auth - JWT, bcrypt
